# 🤖 AI Learning Academy

> **An interactive, beginner-friendly web platform to learn Artificial Intelligence, Machine Learning, and Deep Learning through visual explanations, animations, and hands-on concepts.**

---

## 📌 About the Project

**AI Learning Academy** is an interactive educational website designed to make Artificial Intelligence easier to understand.

Instead of learning AI only through lengthy textbooks or static notes, this platform presents important concepts using:

* 🎨 Interactive visualizations
* ✨ Animations
* 🧠 Concept-based explanations
* 📚 Structured learning topics
* 💡 Examples and intuition
* 🔄 Interactive AI learning components
* 📊 Visual representations of algorithms and models

The goal is to provide a **simple learning path from AI fundamentals to Machine Learning and Deep Learning concepts**.

---

## 🎯 Project Objectives

The main objectives of AI Learning Academy are:

1. Make AI concepts easier for beginners to understand.
2. Provide an organized AI learning roadmap.
3. Explain complex concepts using animations and visualizations.
4. Connect mathematical concepts with AI algorithms.
5. Help students revise important AI/ML/DL concepts quickly.
6. Provide an interactive alternative to traditional static notes.
7. Create a useful portfolio project demonstrating frontend and educational technology skills.

# 🚀 Getting Started

## 1. Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/akshathaa18/AI_Learning_Academy.git
```

---

## 2. Open the Project

```bash
cd AI_Learning_Academy
```

Open the folder in Visual Studio Code:

```bash
code .
```

---

## 3. Run the Website

Since this is a frontend project, you can simply open:

```text
index.html
```

in a web browser.

### Recommended

Use the **Live Server** extension in Visual Studio Code.

1. Install **Live Server**.
2. Open `index.html`.
3. Right-click the file.
4. Select **Open with Live Server**.

The website will open in your browser.
